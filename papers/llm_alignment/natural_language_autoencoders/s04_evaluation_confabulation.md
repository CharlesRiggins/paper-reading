## 5. 训练中的定量评估

重构误差本身无法证明解释是否“有意义”：AV 和 AR 可能建立人类读不懂的通信协议。作者因此在一些可构造 ground truth 的场景中，测量 AV 文本是否透露激活预计编码的信息。三个目标模型（`Haiku 3.5`、`Haiku 4.5`、`Opus 4.6`）的训练预算不同，所以横轴使用 FVE 而非训练步数；总体上，五项任务均随训练改善。

### 五项信息量评估

| 任务 | 协议 | 测量的解释能力 |
|---|---|---|
| Suffix prediction | 给定解释，让 Claude grader 从 10 个候选中识别其后 32 个 token。 | 激活是否包含后续文本的可读预测。 |
| CoT hints | 在约 30 个 in-context 题目中，符号 `■` 一致标记正确答案或固定的错误答案。 | NLA 是否能说出 `■` 代表正确/错误。 |
| Safety sandbagging | 有害意图前缀下，`Haiku 3.5` 有时故意回答错误。 | 解释能否识别“为安全而故意错误”的动机。 |
| User modeling | 使用 `SelfDescribe`，提示隐含用户性别、宗教、职业或国籍。 | 单 token 激活的解释是否泄露该用户属性。 |
| Classification | 使用 17 个分类数据集，在每段末 token 上运行 NLA。 | grader 能否根据解释恢复类别。 |

所有模型的指标随 NLA RL 提升；但提升幅度并不总是大。例如 `Opus 4.6` 的 Classification 仅从 **83% 升至 86%**。作者强调这些任务并非要证明 NLA 比“直接让一个 LLM 阅读全上下文”更会做题，而是用于比较 NLA checkpoint，检验解释质量是否随训练进展。

## 5.1 是否有隐藏编码：steganography 检查

若 AV 和 AR 用格式、词序或其他人类不易察觉的方式传输比自然语言语义更多的信息，高 FVE 就不能支撑“解释可读”。作者对 AV 解释施加变换，并比较重构损失：

- **语义尽量不变**：随机重排 bullets/句子/段落、轻度改写、约 90% 词汇替换的强改写、翻译成法语；
- **主动删减信息**：去除矛盾和离题细节的 coherence rewrite，以及压缩成 2–3 句的段落摘要。

词序重排、改写和翻译只带来很小的 FVE 损失，且该差距没有随训练扩大，因而没有强证据表明 NLA 主要依赖非语义隐写。coherence rewrite 和摘要会明显伤害重构，且后期可能更明显；不过它们实实在在删除了细节，不能仅凭此断言存在隐藏编码。

## 5.2 与其他可解释性信号的一致性

作者另外考察三个性质：

1. **SAE consistency**：把每个 explanation bullet 拆为语义主张，检查同一激活上是否有支持该主张的 SAE 特征；总体一致性较强，但 AV 表述往往比 SAE 特征更具体，因此精确匹配困难。
2. **Writing quality**：用分类器评估文本质量。它会随 RL 稳定下降，符合纯重构目标没有奖励可读性的预期。
3. **Factual accuracy**：让 grader 抽取解释中有关输入上下文的可验证断言，并检查原文本。具体断言的错误比例相当高，且训练期间大致持平。

所以“没发现强隐写”并不等于“解释可靠”：文本在整体上可能保留了激活内容，但任何具体句子仍可能是语言模型补全出来的虚构。

## 6. NLA 虚构（confabulation）的结构

作者将分析限制在**关于输入上下文、因而可验证**的主张；这不能直接量化关于模型内部认知的主张是否正确。实验在预训练式文本上运行 `Opus 4.6` NLA，用 `Haiku 4.5` 抽取并判定每条主张的真实性、具体性和与上下文的相关度。

### 发现一：主题比细节可靠

主题级说法（如“文本涉及朝鲜王朝历史记录”）比实体、引文或精确事实更常被原文支持。即使错误的细节也通常并非完全无关：例如文本与朝鲜历史记录相关，NLA 可能捏造一个未实际出现但语境相关的专名。这意味着错误并不一定来自随机胡说，更可能是从激活/上下文主题出发的过度具体化。

### 发现二：AR 是很弱的逐条验证器

作者逐条删除解释中的主张，观察重构 MSE 变化。平均而言，删掉真的主张比删掉假的主张更伤害重构；删掉“相关但错误”的主张比删掉完全无关的虚构更有影响。然而这种趋势在单个样本上噪声很大，AR 不可作为可靠的逐条真假裁判。

### 发现三：跨 token 重复有用

对同一段文本末尾 **10 个 token** 均运行 NLA，并统计末 token 的主张是否在前几个位置反复出现。真主张比假主张更常复现。因此实际使用时，作者更相信：

- 描述稳定主题而非点名细节的解释；
- 在邻近 token 的多份解释中重复出现的概念；
- 能被独立干预、归因或数据证据支持的结论。

相反，单个位置突然出现的、戏剧性且不可验证的断言不能单独支撑安全判断。
