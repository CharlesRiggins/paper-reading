# Real-Time Detection of Hallucinated Entities in Long-Form Generation
arXiv: 2509.03531 | Oscar Obeso, Andy Arditi et al. (ETH Zürich & MATS, 2025)
Code: https://github.com/obalcells/hallucination_probes

## Files

- `s01_introduction.md` — Abstract plus Section 1. Motivates streaming, token-level hallucination detection for long-form generation, arguing entity-level labels (not claim-level) preserve token alignment and enable real-time monitoring. Linear probes hit 0.87 AUC vs 0.71 for semantic entropy on `Llama-3.3-70B`; LoRA probes reach 0.90.
- `s02_related_work.md` — Section 2. Surveys three families: internal-representation probing (linear/MLP probes, mechanistic interpretability "knowledge features"), uncertainty-based detection (length-normalized log-prob, semantic entropy and its probe variant SEPs), and expensive external verification pipelines (SAFE, FactScore, FacTool) whose latency precludes streaming use.
- `s03_methodology.md` — Section 3. The LongFact++ prompt set (10× LongFact, four prompt categories) elicits entity-dense generations that `Claude 4 Sonnet` + web search labels as Supported/Not Supported. Probes are linear value heads (optionally + LoRA) on layer ⌊0.95×num_layers⌋, trained with a combined token-wise + span-max BCE loss (ω annealed 0→1, entity tokens up-weighted by α=10). Label quality: 84% human agreement, 80.6% recall, 15.8% FPR.
- `s04_long_form_detection.md` — Section 4. Setup (5 instruction-tuned models; ~25k-sample training corpus) and Table 1 results: LoRA probes reach 0.89–0.93 AUC on long-form (LongFact/HealthBench), 0.97–0.98 on TriviaQA, and 0.87–0.88 on out-of-distribution MATH, all beating uncertainty baselines capped near 0.76.
- `s05_additional_experiments.md` — Section 5. Asymmetric generalization (long→short transfers, short→long does not, ~0.10 AUC gap); strong cross-model transfer (within 0.02–0.04 of same-model); KL-regularization Pareto frontier for detection-vs-behavior trade-off (Table 2: λ_KL=0.50 gives 0.0046 KL, 52.8% win rate, 0.8898 AUC); and selective-answering proof-of-concept on SimpleQA.
- `s06_07_limitations_discussion.md` — Sections 6 & 7. Annotation noise (80.6% recall ceiling), insufficient practical reliability (~70% R@0.1; halving hallucinations sacrifices ~50% of correct answers), and scope limited to entity hallucinations despite MATH generalization. Discussion frames the work as a foundation for scalable streaming hallucination monitoring.
- `s08_references.md` — Full 38-entry reference list spanning probing, semantic entropy, mechanistic interpretability, factuality benchmarks, and the model/dataset sources used.
- `s09_appendix_dataset.md` — Appendices A–C. Code/dataset release URL; annotated HealthBench/MATH samples (Figs 8–9); LongFact++ construction (1,000 seed topics × 20 questions, biographies, citation-focused, legal prompts); dataset splits and per-model test sizes; the fact-verification system prompt (Fig 10).
- `s10_appendix_evaluation_label_quality.md` — Appendices D–E. Per-task scoring protocols (span-max for token methods; k=10 sampling for semantic entropy); label-quality validation via human agreement (84%), synthetic-hallucination injection (729/904 detected, 100% precision on flagged spans), and cross-annotator robustness (Claude Sonnet 4 vs Opus 4, ~0.01 AUC difference, Table 3).
- `s11_appendix_baselines.md` — Appendix F. Formal definitions of token-level entropy (Eq 3–4) and perplexity (Eq 5–6); semantic-entropy clustering via bidirectional entailment judged by `GPT-4.1` (Eq 7–8) with per-task sampling setup; black-box self-evaluation experiments showing short-form AUC 0.81–0.89 collapsing to 0.58–0.68 on long-form (Fig 11).
- `s12_appendix_extended_results.md` — Appendices G–H. LongFact++ results for primary models (Table 4: LoRA up to 0.9265 AUC) and secondary models Gemma/Qwen/Mistral (Table 5); selective-answering results across all five models (Table 6: conditional accuracy roughly doubles at t=0.5).
- `s13_appendix_impact_model.md` — Appendix I. Quantitative behavior-preservation analysis via KL divergence, Arena-Hard-Auto win rate (Table 7: λ_KL=0.90 gives 53.3% win rate), and MMLU; qualitative cases where LoRA induces epistemic caution (Figs 14–17: incorrect referee names, anagram failures, lithium dosing, unverifiable citations).
- `s14_appendix_assets_compute.md` — Appendices J–K. Tables 8–9 listing the five models and four datasets used with their licenses (Llama community license, Apache-2.0, Gemma, MIT); compute statement (LoRA probe training for `Llama-3.1-8B` takes <2 hours on one H100).
