# An off switch for dual-use knowledge in AI models

*Anthropic Alignment, 2026-07-08. 本文介绍 AE Studio 与 Anthropic 合作开展的研究。*

## 1. 问题：把访问控制与知识控制分开

前沿 AI 模型是大型知识库，其中有些知识具有**双用途（dual use）**：网络安全知识既可帮助修补关键漏洞，也可能被用来利用漏洞；病毒学知识既可帮助研究疫苗，也可能被恶意用于设计致命病原体。

文章提出理想的能力治理应同时达到三件事：

1. 以尽可能精细的方式限制双用途能力的访问；
2. 允许经过审核的可信用户为了有益目的访问同样的能力；
3. 不影响模型在其他任务上的表现。

当前的防护层主要是拒答训练，以及筛查输入与输出危险内容的分类器。这些机制保护模型**输出**，但并不改变基础模型内部已经存储的知识。因此，坚定的攻击者仍可能通过越狱尝试绕过外层防护，取得双用途知识。

## 2. 与过滤和可移除知识定位的关系

文章将 `GRAM` 置于两条已有研究路线之后：

- **预训练数据过滤：** 先前工作曾从预训练数据中排除化学、生物、放射与核武器（CBRN）相关信息；
- **可移除参数切片：** 后续 `Selective Gradient Masking`（`SGTM`）工作表明，双用途知识可以被限制在模型权重中可删除的一小部分。

本文认为，过滤仍是一种较粗粒度的手段。它产生的是一个能力集合固定的模型：若开发者想同时拥有“可讨论高级病毒学、只部署给审核过的生物安全实验室”的版本，以及“不能讨论高级病毒学”的更广泛部署版本，就必须分别训练两个模型。对昂贵的前沿模型而言，这种多次完整训练的成本可能不可承受。

因此，文章介绍与 AE Studio 合作的 `GRAM`（Gradient-Routed Auxiliary Modules）研究。其目标是以**训练一个模型**的代价，获得分别过滤多个领域时才会产生的多种模型配置。作者明确强调，这仍是初步研究：`GRAM` 未应用于 Anthropic 的任何生产模型，也不确定未来是否会应用。
