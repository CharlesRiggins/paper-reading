# 摘要与引言：LLM 是否有一个可访问的「工作空间」？

## 研究问题

论文不讨论模型是否具有主观体验，而是问一个可检验的功能问题：在模型的大量内部处理里，是否存在一个小的表示集合，具有类似人类 **access consciousness / global workspace** 的性质——可被语言报告、受目标控制、供不同下游计算灵活使用，而不是仅服务某个局部自动回路？

作者的答案是：在所测 Claude 系列模型中，存在一个候选集合 **J-space**。它只占激活方差的一小部分，却承担大量可报告、显式推理和跨任务复用的作用。

## 核心对象

- **残差流**：每个 token、每层都维护的共享向量 $h_{\ell,t}$；所有 MLP 和注意力模块都从中读取并写回。
- **Jacobian lens / J-lens**：以中间激活对最终输出的平均一阶因果效应为基础，为每层构造「词 token → 残差流方向」的字典。读出高分词可近似解释该激活「在合适条件下倾向使模型说什么」。
- **J-space**：由少量 J-lens 向量的稀疏、非负组合构成的集合。不是一个普通线性子空间；它是过完备字典在稀疏度约束下形成的稀疏子框架。
- **workspace / sensory / motor 区域**：早层读数贫乏（sensory）；中间层有稳定抽象内容（workspace）；末层读数转向下一 token（motor）。Sonnet 4.5 的经验范围约为 L38–L92。

## 论文主张与证据链

| 主张 | 主要实验 | 关键结果 |
|---|---|---|
| J-space 支持报告 | 概念替换、注入后自省报告 | J-space 分量虽只占概念向量中位约 6–7% 方差，却几乎承载报告的因果作用；非 J-space 剩余分量的效应在钳制 J-space 后近乎消失。 |
| 可按指令进入/退出 | 边抄写边「想 X」、心算、数行宽 | `orange`、`nine`、`seven`、`forty` 等在不输出时仍进入 lens；「ignore」能降低但「don't think」常触发白熊效应。 |
| 中介内部推理 | 两跳事实、押韵规划、中文反义词、bandit | 替换中间概念会系统性改写答案；两跳任务替换成功率为 Haiku 54%、Sonnet/Opus 70%。 |
| 服务灵活而非自动处理 | 语言识别、行宽、14 项能力的整体消融 | 显式报告与灵活推断依赖 J-space；续写、异常检测、浅层分类/抽取等可基本绕过。 |
| 具有工作空间结构 | 分层统计、容量、MLP/attention 权重分析 | 中间层出现稳定且有限内容，典型占用约 25 个 J-lens 方向、解释增量方差不超过 10%，并被许多 MLP/特定注意力头优先读取和传输。 |

## 为什么不是「把 logit lens 换个名字」？

普通 logit lens 直接把中间激活过 unembedding，隐含 $J_\ell=I$；在末层尚合理，在早中层常读到噪声。J-lens 显式估计从中间层到输出层的平均因果线性映射，能在更早的 workspace 层读出中间变量。tuned lens 虽更擅长预测最终下一 token，却往往直接「跳到答案」，反而遮蔽中间计算。

## 阅读时应保持的界限

1. 这是对若干 Anthropic 生产模型及特定干预设置的实证结论，不是一般 transformer 定理。
2. 读到 token 不是完整语义解析：单 token 词表限制会把 `blackmail` 拆成片段，也不能表达绑定关系。
3. 「像全局工作空间」是功能类比，不推出模型具有现象意识；作者也明确保留该哲学问题。
