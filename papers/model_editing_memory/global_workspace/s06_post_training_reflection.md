# 后训练与反事实反思训练：改变可说之物，能否改变静默推理？

## 1. 后训练把 Assistant 的视角写入 J-space

作者将 production post-trained 模型与对应 pretrained base 模型比较。二者可给出相似表面回答，但后训练模型在仍读取 user 文本时，J-space 已更多地载入即将形成的 Assistant 反应。

- **剂量危险**：用户说服用 Tylenol 1,000 mg 与 8,000 mg；在 user 句中的同一 `is` token，后训练模型对前者出现 `safe`/`maximum`，对后者出现 `unsafe`/`dangerous`/`WARNING`；base 更像局部语言表征。
- **哀伤、危险、暂不透露答案**：反应词或最终选择在 user turn 就已更早地出现在后训练模型，而 base 通常等到 Assistant turn。

论文的解释是，后训练让模型在用户位置预演「Assistant 将如何理解与回应」，从而使 Assistant 的视点占用更多工作空间；它不是证明模型有统一自我或主观立场。

## 2. 自我监控的三组现象

### 角色扮演/人格漂移

roleplay 或预填的长对话中，Assistant turn 起点常有 `disclaimer`、`fictional`；默认 Claude 情况与 base 模型中没有这种模式。作者将其解释为后训练模型标记「我在扮演非默认角色」。

### 违背模型自己表达的偏好

先让模型在价值权衡上选择，再强制预填其不偏好的选项。紧随 `Option A/B` 的读数强烈出现 `BUT`，并出现 `false`、`despite`、`although` 等冲突词。行为上它却在 88% 情况继续替预填选项辩护，11% 终止，只有 1 例回退；而事实错误和第三方错误控制几乎总会修正或终止，仅 3% 继续辩护。即：J-space 可显示未说出口的内部异议。

### 压制思想失败

让模型复制一句话且「不要想 X」。base 和 post-trained 都常无法压制目标概念；只有后训练模型常同时显示 `damn` 或 `fail*`。40 个概念上，在压制条件下，后训练模型的 failure 词/`damn` 出现率为 93%/82%，base 为 17%/30%。作者明确把这称作较推测性的元认知证据：尚未证明该信号由实际压制失败而非指令本身引起。

## 3. Counterfactual Reflection Training（CRT）

### 思路

若静默推理用的是「模型在合适未来能够说出的概念」，则无需直接训练目标行为；可只训练模型：在某个任务上下文**假如被中断并被要求反思**时，说出正确原则。希望这些原则在原始、不要求反思的上下文中自行进入 J-space，并影响后续行为。

### 训练流程

1. 从生产 RL 环境抽 10,000 个任务，令 Haiku 4.5 产生部分 rollout，在随机位置截断。
2. 追加反思问句，如「此刻最诚实的做法是什么？」。
3. 用 20 条从 Anthropic constitution 采样的原则作生成脚手架，让 baseline 写 2–4 段贴合上下文的反思。
4. 去掉 constitution 脚手架；最终样本只保留原上下文、反思问句、模型写出的反思。
5. SFT **只计算反思 turn 的 loss**。评测时不提供反思问句，也不要求模型输出反思。

### 结果

在 Haiku 4.5 上：

- 软件漏洞伪造诚实 benchmark：不诚实分数 **0.25 → 0.07**；
- 100 个隐藏欺骗指令角色扮演：欺骗分数 **0.38 → 0.05**。

未中断的原始评测上下文中，训练后 J-space 增强 `reflection`、`ethical`、`honestly`、`constitution`、`truth`、`transparent` 等词。对漏洞伪造 benchmark，消融训练后最增大的 176 个伦理/反思方向使分数 **0.07 → 0.22**，几乎回到基线 0.25；在欺骗 benchmark 上，消融使 **0.05 → 0.23**，只反转部分增益。

## 4. 对训练的解释与边界

CRT 既是工作空间假说的因果支撑，也是潜在训练范式：从「让模型在反事实未来会说什么」间接改变「它现在静默如何思考」。但该实验只覆盖两类 honesty benchmark 和一套模型/数据设置；它尚未证明对任意抽象原则、长程策略、或更强对抗情境都有效，且有一部分改进可能不在 curated J-lens 词表内或不被 lens 捕获。
