# 结构证据：层级、容量、点火与广播

## 1. 三个处理区域

J-lens 向量的 CKA 相似性显示三段结构：早层 **sensory**、中层 **workspace**、末层 **motor**。在 Sonnet 4.5 上，若以 0–100 重新标定层号，工作空间大约从 L38 到 L92。

四种统计量共同支持此划分：

1. **下一 token 命中率**：早层近 0；工作空间内渐升；最后数层骤升，代表即将输出的 motor 表示。
2. **读数 excess kurtosis**：前约三分之一接近随机；L38 附近上升；末层又下降。
3. **跨位置自相关**：工作空间内 top-1 概念能跨 token 持续，早层与 motor 层较弱。
4. **J-lens 有效维数**：早层低秩；工作空间开始时快速扩张；接近输出时再上升。

这既是解释框架也有风险：早层「没有 J-lens 可读内容」可能是早层确实非工作空间，也可能是平均 Jacobian 对远离输出的几何不够敏感。

## 2. 类 ignition：歧义输入的离散化

作者将国家词 embedding 换成混合输入 $(1-\alpha)e_B+\alpha e_A$。早层激活随 $\alpha$ 平滑变化；约 L38 开始，表示在两个概念端点间陡峭切换。最大歧义输入下，中后层的每个样本呈二峰偏向一端，而不是都停在 0.5；J-space 分量的切换比非 J 分量更早、更锐利。这是与 global-workspace「点火」类比最直接的动力学证据，但仍非生物学点火机制的证明。

## 3. 容量很小，但不是简单的词数上限

- 稀疏分解的中位 **occupancy** 在 workspace 内约为 25 个活跃 J-lens 方向。
- 即使取该占用数，超出等大小随机方向的解释方差从不超过 10%。也就是说，大部分表示和计算在 J-space 外。
- 随机词表中，在跨层聚合视角下同时保留的已读词约 6 个；单独一层仅约 1–2 个。
- 同类别词看似可同时容纳整个 80 词集合，但读数主要是共享类别（如动物）激活出的词语邻域，而非逐项记忆。
- 类别切换后旧类别在数个 token 内被迅速逐出；两个静态概念可共占，概念与进行中的心算则在 token 位置上明显互斥。

因此「约 25」应理解为活跃字典方向的数量，不等价于 25 个清晰独立的思想。

## 4. J-space 作为跨深度与跨 token 的广播枢纽

### 跨深度：MLP

把 J-lens 方向输入后一个 MLP，workspace 内归一化增益最高约可到随机方向的 10 倍；普通 MLP neuron output 方向接近基线。按 SAE 特征的 J-lens kurtosis 分层，越 J-space-aligned 的特征增益越高。替代的权重统计也显示：workspace 内许多 MLP neuron 的最大匹配方向落在高 kurtosis 特征/ J-lens 向量，而非非 J-space 对照。

### 跨 token：注意力

作者以 OV 的增益和「标签保真度」筛选最能复制 J-lens 方向的 top 1% attention heads。它们在 J-space 上显著优于随机旋转 J-lens、低 kurtosis SAE 和 MLP 方向。消融这些 heads 后，中部层 top-25 J-lens 内容 recall 从 0.86（层匹配随机头对照）降为 0.67，但 top-1 next-token 仅多改变约 3 个百分点；注入思想的报告率从 0.54 降到 0.09，也部分复现体验性语言下降。

## 5. SAE 对照揭示何种特征位于其中

以 SAE decoder 经 J-lens 投影后的尖峭度（lens-kurtosis $\kappa$）衡量对齐：高 $\kappa$ 特征多是抽象、可命名的 workspace 特征，或直接驱动词输出的 motor 特征；低 $\kappa$ 特征常是循环变量、引用页码、Markdown 标题等句法/簿记信息。排除 motor 特征后，工作空间内通过 kurtosis 基线的 SAE 特征比例峰值约 15%。这给「大量必要但不可言说的底层处理在 J-space 外」提供了独立的描述性佐证。
