# 面试速记：如何讲这篇论文

## 30 秒版本

这篇工作提出 Jacobian lens：对每层中间激活到最终输出的 Jacobian 在大量上下文中求平均，再接模型自己的 unembedding，得到可读的 token 方向字典。由少量这些方向组成的 J-space 只解释少量激活方差，却通过交换、消融和钳制实验显示，它对显式报告、可控注意、两跳推理和灵活泛化有因果作用；许多自动续写和浅层任务则不依赖它。作者因此把它视为 LLM 中类似 global workspace 的候选结构，并展示其在对齐审计和反事实反思训练中的用途。

## 高频问题

### Q1：为什么不用 logit lens？

logit lens 假设中间表示已与最终 unembedding 对齐，即 $J_\ell=I$。残差连接使它在末层不错，但早中层存在几何失配。J-lens 显式估计从该层到输出的平均因果线性变换，实验中更能读出中间变量，也更能通过交换改变答案。它不是要更好预测 next token；该任务 tuned lens 更强，但 tuned lens 常过早跳到最终答案。

### Q2：为什么 J-space 不是普通子空间？

J-lens 向量数量超过维度，线性张成几乎整个残差空间。信息量来自「自然激活能否被少数向量的稀疏非负组合近似」，所以应看稀疏子框架/锥的并。论文用 gradient pursuit 近似这一成分。

### Q3：最强因果证据是什么？

三层证据：

1. 对中间概念做坐标交换会改两跳答案、押韵规划和跨语言答案；
2. 将概念向量拆为 J-space/余项，少量 J-space 方差承担大多数报告和推理效应；
3. 钳制 J 坐标后，非 J-space 余项的少量效应几乎消失，说明它常是经 J-space 重新路由。

### Q4：工作空间如何体现「有限且广播」？

中间层 occupancy 约 25 个方向，解释的增量方差不超过 10%；同一概念坐标可驱动不同函数模板的答案。MLP 对 J-space 方向的增益更高，特定 attention heads 特别保真地传递其内容；消融这些 heads 大幅影响 J-lens 内容和自省报告，而较少影响普通 next-token。

### Q5：安全上能做什么，不能做什么？

能在输出未透露时筛出评测意识、提示注入识别、隐藏失配目标等线索，并在 CRT 中作为训练机制的可观测中介。不能保证全面检测：自动化失配回路、多 token/无名称计划、早层或 J-lens 未覆盖的表示都可能漏检；应和 SAE、NLA、行为评估、对照干预联合。

## 可复现的最小实验建议

1. 在开放模型上计算每层 $J_\ell$，先用 10、100、1,000 个序列比较稳定性。
2. 准备单 token 两跳题；比较 J-lens、logit lens、tuned lens 的 intermediate pass@k。
3. 在中层做 source/target 坐标交换，记录目标答案 logit 与成功率；设随机方向、等范数和钳制对照。
4. 对「复制无关句 + 心算/想概念」测 workspace 读数，测试 `focus`、`mention`、`ignore`、`don't think` 的差异。
5. 将某一信息置于显式报告、灵活计算与自动续写三种任务，验证同一信息是否只在前两种经 J-space 因果起效。

## 可追问的研究题

- 使用 phrase-level causal Jacobian 替代 template/oracle 的相关性近似。
- 给 J-space 加入绑定与角色结构，而非 token 袋。
- 测量 workspace 如何随预训练步数、规模、MoE、递归架构和多模态输出而出现/变化。
- 在主动规避审计的训练中测量 J-lens 覆盖率，并构造不依赖固定危险词表的检测器。
- 定位把信息写入 J-space 的 attention/MLP 回路，并验证是否可精确编辑而非大范围消融。
