# 功能证据：J-space 如何像全局工作空间

## 1. 可报告性：少量 J-space 分量支配报告

**直接报告。** 模型被要求先想一个类别成员、再用一个词说出它。冒号前的 J-lens 已对未来回答排序；把自发项目（如 `Soccer`）的 lens 坐标替换为未位列 top-10 的同类项目（`Rugby`），模型会报告替换后的项目。

**自省报告。** 在 user turn 注入一个 J-lens 向量（如 `lightning`）后，模型只在后来被询问「检测到了什么」的恰当位置报告该概念，而不会立即不受控地输出它。这支持「可在适当条件下报告」而非「必然说出」。

**特权性测试。** 概念平均向量被拆成 $k=16$ 的 J-space 部分和余项。前者仅占中位约 6–7% 方差，却能使类别替换目标进入 top-5（59%，纯 J-lens 为 88%）；非 J-space 部分仅 5%。钳制 J 坐标后，余项的残余报告效应趋近于零，说明其少量影响通常仍要经 J-space 重写。

## 2. 定向调制：模型可以「把某事放在心里」

实验要求模型一边复制无关文本，一边集中于概念、心算或数行宽。输出表面保持复制，J-lens 却在中间层显示：

- 集中柑橘：`orange`、`lemon`，以及 `thinking`、`focused`；
- 默算 $3^2-2$：`arithmetic → nine → seven`；
- 静默数行宽：`lines/length → forty`。

多种任务上，明确 `focus` 指令显著提高目标进入 top-1 的率；`ignore X` 可降低但不清零，`don't think X` 往往并不成功（白熊效应）。同一文本在「预测下一个词」时可正确利用语法/方言/时态，却不在 J-space 中写出属性名；改问「这个属性是什么」后，属性名进入 J-space。这是「信息存在」与「信息被工作空间显式化」的关键区分。

## 3. 内部推理：替换中间概念会改写结论

- **两跳事实**：`spider` 换 `ant`，`8` 换为 `6`。
- **诗歌规划**：第一行后将计划韵脚 `fight` 换为 `light`，第二行早期选词和终韵都随之改变。
- **跨语言推理**：中文小的反义词任务中，读数出现英语中间词 `big`；交换为 `long` 后中文答案由「大」变「长」。
- **策略选择**：bandit 情境的 `repeat`/`switch` 表示交换会翻转 A/B 决策。

50 个两跳题上，J-lens 坐标交换使目标答案居首的比例为 Haiku 4.5 的 54%、Sonnet 4.5 与 Opus 4.5 的 70%。中间变量交换的有效层深比直接交换答案中位早约模型深度的 17%，排除「中间词向量偷偷含答案」这一简单解释。对 90 题的 probe 分量拆解中，J-space 部分交换成功 61%，非 J 部分仅 28%，再钳制 J-space 后降到 6%。

## 4. 广播意义的功能测试：同一概念可供多种函数使用

同样将 `France` 换为 `China`，无论问题问首都、语言还是大洲，模型都趋向输出中国对应的答案。跨国家、月份、动物和数字词 16 个函数模板、192 个交换中，常规强度成功 76 次，双强度成功 101 次。成败由源概念原本的 **workspace loading** 预测：国家最强，数字词最弱。

## 5. 灵活推理依赖 J-space，自动处理未必依赖

### 相同信息、不同任务

对西班牙语文本做 `Spanish → French` 交换：

- 直接命名语言与问该语言的作者/问候语/货币，答案会随交换改变；
- 续写西语文本、检测插入的法语句，基本不受影响。

对文本行宽做 40s→60s 数字交换也类似：问实际长度或其英文首字母时会改答；保持换行格式的自动续写仍能正常工作，且普通续写时数字根本不出现于 lens。

### 全局消融

每层投影掉 top-10 活跃 J-lens 方向（避开干净前向中 top-10 输出词）会使多跳推理接近失效，却对预训练文本的多数 next-token 预测影响小。14 项任务中，MMLU 选择题、odd-one-out、SQuAD 抽取、情感与 CoLA 几乎不受影响；Caesar cipher、类比、摘要、TriviaQA、多跳、翻译和十四行诗大幅下降。显式 CoT 的 GSM8K 比直接作答更抗消融，符合「中间步骤外写到上下文后，内部工作空间负担下降」的解释。

**应有的谨慎：** 这些结果将 J-space 依赖称作「灵活」、不依赖称作「自动」，是操作性分类；它不等同于人类心理学中的自动性，也不保证覆盖所有任务。
