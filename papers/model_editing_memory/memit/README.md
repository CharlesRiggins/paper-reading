# Mass-Editing Memory in a Transformer
arXiv: 2210.07229 | Kevin Meng et al. (MIT CSAIL / Northeastern University / Technion, 2022)
Code: https://github.com/kmeng01/memit

## Files

- `s01_abstract_intro.md` — Introduces MEMIT’s goal: directly editing transformer weights to add or replace thousands of factual memories. The section motivates model editing as an alternative to expensive retraining and explains why prior single-edit methods fail to scale. It frames language-model knowledge as $(s,r,o)$ tuples and previews the main result: successful bulk edits in `GPT-J` and `GPT-NeoX` while preserving generalization, specificity, and fluency.
- `s02_related_work.md` — Places MEMIT between classical knowledge bases, LMs-as-knowledge-bases, hypernetwork editors, and direct model editing. It explains why structured knowledge bases are easy to update but incomplete, while LLM knowledge is broad but implicit and hard to control. The section contrasts MEMIT’s explicit associative-memory update with KE, MEND, SERAC, ROME, and neuron-editing approaches.
- `s03_preliminaries.md` — Defines the autoregressive transformer notation, the residual stream equations, and the factual edit request set $\mathcal{E}$. It formalizes facts as non-conflicting subject-relation-object triples and distinguishes efficacy, generalization, specificity, and fluency. This file sets up why mass editing is harder than simply making one prompt return a desired token.
- `s04_method.md` — Details MEMIT’s mechanism. Causal tracing identifies a critical MLP layer range, e.g. $\mathcal{R}=\{3,4,5,6,7,8\}$ for `GPT-J`; MEMIT then treats MLP output matrices as linear associative memories. The file preserves the batch update derivation, including $\Delta=RK_1^T(C_0+K_1K_1^T)^{-1}$, and explains how desired hidden vectors $z_i$ are spread across multiple layers.
- `s05_experiments.md` — Covers the `zsRE` and `COUNTERFACT` experiments, baselines, scaling curves, category analysis, and mixed-relation tests. Key results include **50.7** score for 10,000 `zsRE` edits on `GPT-J`, **85.8** `COUNTERFACT` editing score on `GPT-J`, and **82.0** on `GPT-NeoX`. The tables show that MEMIT preserves fluency much better than fine-tuning and scales far beyond ROME and MEND.
- `s06_discussion_ethics_reproducibility.md` — Summarizes the paper’s conclusion that interpretability-guided parameter edits can scale to large fact sets. It notes limitations: MEMIT handles directional $(s,r,o)$ associations rather than temporal, spatial, mathematical, procedural, or symmetric knowledge. It also records the ethical caution that model editing can fix stale knowledge but could also insert false information, plus the GPU requirements for reproducing experiments.
- `s07_references.md` — Full 54-entry reference table. It includes background on knowledge bases, factual probing, transformer interpretability, model editing methods, and the software/model infrastructure used in the experiments.
- `s08_appendix_causal_tracing.md` — Explains the causal tracing procedure used to localize factual recall in `GPT-J`. The appendix describes corrupting subject-token encodings, restoring hidden states or module outputs, and comparing attention-vs-MLP interventions. The main takeaway is that MLPs in a mid-layer range mediate factual recall, justifying MEMIT’s edit target.
- `s09_appendix_implementation_metrics.md` — Captures implementation details for FT-W, MEND, ROME, and MEMIT, including layer choices, optimization steps, covariance samples, $\lambda$ values, norm clamps, and runtimes. It also formalizes the `zsRE` and `COUNTERFACT` metrics, including ES, PS, NS, RS, GE, and harmonic editing scores.
- `s10_appendix_mixed_demos_ablations.md` — Covers mixed-relation editing, two demonstrations, and ablations. MEMIT’s mixed edit performance tracks the average of individual relation performance, astronomy edits raise `GPT-J` constellation recall from **53%** to **86%**, and ablations confirm that mid-layer MLP edits outperform late-layer or attention edits. The $\lambda$ ablation shows the preservation-vs-efficacy trade-off peaking near $10^4$.
